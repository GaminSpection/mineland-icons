# Mineland item icons

The Steam inventory icons for [Mineland](https://store.steampowered.com/app/3087620/), served by
GitHub Pages and referenced by the game's item definitions:

- `small/<item>.png`: 200x200, `icon_url`
- `large/<item>.png`: the item's full art, `icon_url_large`

Generated by `Steam/export_icons.py` in the game's repository. Do not edit by hand. A changed
icon gets a new file name, since Steam caches images by URL.
